# public/projects

Put project screenshots here and reference them from `src/data/projects.ts`:

```ts
image: "/projects/my-project.png",
screenshots: ["/projects/my-project-2.png"],
```

The `example-*.svg` files are placeholders for the sample projects — delete them
once you add your own.

Recommended: 16:10 or 16:9, at least 1200px wide, PNG/JPG/WebP.
