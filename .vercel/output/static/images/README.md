# public/images

Put personal images here.

- `profile.jpg` — your profile photo. Then set `avatar: "/images/profile.jpg"` in
  `src/data/portfolio.ts`. Leave `avatar: ""` to show an initials avatar instead.
- Optional `og-image.png` (1200x630) for social previews — reference it with an
  absolute URL in `portfolio.meta.ogImage`.

Missing images degrade to a placeholder tile, never a broken image.
